# Decisions Log

Every design and implementation decision for the SARIS Company Portal is recorded here.

- **Confirmed** decisions are binding on all implementation work.
- **Proposed** decisions are awaiting confirmation in the Claude.ai design Project.
- **Superseded** decisions are kept for history. Never delete an entry; supersede it.
- Number entries in order (`D-001`, `D-002`, ...). Never reuse a number.

## Entry format

```
## D-xxx: [Short title]
- Date: YYYY-MM-DD
- Status: Proposed | Confirmed | Superseded by D-xxx
- Source: Claude.ai design chat | Claude Code | Stakeholder
- Decision:
- Reason:
- Affects: [entities, modules, or design docs]
```
