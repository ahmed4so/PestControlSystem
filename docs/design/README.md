# Design Deliverables

The approved design deliverables produced in the Claude.ai design Project go in this folder. They are binding for implementation, second only to confirmed entries in `../decisions-log.md`.

## Naming

Prefix each file with a two-digit number and use a short kebab-case name, for example:

- `01-architecture.md`
- `02-data-model.md`
- ...
- `08-tech-stack.md` (fills in the Tech stack section of `CLAUDE.md`)

## Rules

- Only add a document here once it has been approved in the design Project.
- To change an approved document, update it here and record the change in `../decisions-log.md`.
- Claude Code reads these documents but does not change their design content. Gaps or conflicts are raised with the user and logged as `Proposed` decisions.
